# WDD 231 Course Home Page

## Folder structure

- `index.html` — course home page
- `styles/small.css` — mobile-first styles
- `styles/larger.css` — responsive media queries
- `scripts/navigation.js` — accessible responsive menu
- `scripts/date.js` — copyright year and last modified date
- `scripts/courses.js` — course array, filters, course cards and `reduce()` credit total
- `images/logo.svg` — lightweight SVG site logo

## Before submitting

1. Open the `wdd231-course-home` folder in VS Code.
2. In `scripts/courses.js`, change `completed: false` to `completed: true` only for courses you have personally completed.
3. Check the course credits against the official course array provided in the WDD 231 assignment. Update the `credits` values if the official source differs.
4. Replace the LinkedIn placeholder URL in `index.html` with your actual LinkedIn profile URL.
5. Add your own optimized portrait photo if required. Keep it at or below 125 kB and update the Student Photo section.
6. Create your Chamber and Final project pages in the `chamber/` and `project/` folders, or update those navigation links when your project files are ready.
7. Test at 320px, tablet and desktop widths. Run the HTML/CSS validators and Lighthouse in a private browser window.

## Publish

Commit and push the contents of this folder to the root of your GitHub repository named `wdd231`. GitHub Pages should then publish it at:

`https://adeoyej1.github.io/wdd231/`

The assignment's official course list is the source of truth for course data and credits. This starter array contains the six courses listed in the first Web and Computer Programming certificate; verify its credit values and update completed flags before submission.
